# Kodutöö 1

Numbri arvamise mäng

Programm valib suvalise arvu 0-100. Küsib kasutajalt pakkumise, mis arv olla võiks. Siis annab tagasisidet, kas pakutud arv on suurem või väiksem programmi poolt valitud arvust.

Teada probleemid: mitte int sisendi puhul programm jookseb kokku.
